# CheckCopyRun

Проверяет, копирует и запускает приложения из папки-источника в папку назначения.

## Что делает

- Хранит несколько профилей: папка-источник → папка назначения → запускаемый файл.
- Сравнивает содержимое обеих папок и показывает, что изменилось.
- Копирует только изменения, сохраняя прошлые версии — к любому снимку можно вернуться.
- Умеет работать в режиме зеркала: лишнее в папке назначения удаляется и сохраняется в резервную копию.
- Запускает приложение после копирования, проверяет профили при старте и следит за изменениями в источнике.

Всё это — в одном действии: нажали кнопку, программа проверила, скопировала и запустила. Если запускать ничего не нужно, копирование всё равно работает — просто оставьте поле «Запускаемое приложение:» пустым.

## Системные требования

- Windows 10 или Windows 11.
- Ничего дополнительно устанавливать не нужно: всё необходимое уже в архиве.
- Права администратора не требуются — программа работает с обычными папками и хранит свои данные в профиле пользователя.

## Установка и запуск

Программа распространяется архивом с папкой `CheckCopyRun`. Установка не требуется.

1. Распакуйте архив в любую удобную папку — например, `D:\Tools\`.
2. Откройте получившуюся папку `CheckCopyRun` и запустите `CCRun.exe` двойным щелчком.
3. Для удобства можно создать ярлык на рабочем столе: правой кнопкой по `CCRun.exe` → «Отправить» → «Рабочий стол (создать ярлык)».

Важно:

- Запускайте `CCRun.exe` прямо из распакованной папки. Не переносите `.exe` в другое место по отдельности: рядом с ним лежат файлы, без которых программа не стартует.
- Не запускайте программу изнутри архива — сначала распакуйте, иначе часть ресурсов будет недоступна.
- При первом запуске Windows может показать предупреждение SmartScreen — это обычное поведение для программ без цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

### Обновление до новой версии

1. Закройте программу полностью — в том числе из системного трея («Выход» в меню значка).
2. Распакуйте новый архив в отдельную папку.
3. Запустите `CCRun.exe` из новой папки.

Профили и настройки при этом сохранятся: они лежат не рядом с программой, а в вашей папке «Документы» (см. раздел «Где хранятся данные»). Старую папку с программой после проверки можно удалить.

## Быстрый старт

1. Запустите приложение.
2. Нажмите «Добавить профиль» в боковом меню.
3. В поле «Копировать из:» выберите папку-источник — например, папку со свежей сборкой приложения.
4. В поле «Копировать в:» выберите папку назначения.
5. Если после копирования нужно запускать программу, выберите файл в поле «Запускаемое приложение:» и отметьте «Запускать приложение после копирования».
6. Проверьте опции профиля: «Создавать резервную копию изменённых файлов» (включена по умолчанию), «Режим зеркала», «Проверять директорию при запуске CheckCopyRun», уведомления.
7. Нажмите «Копировать» в профиле или кнопку ▶ в боковом меню. Программа проверит папки, скопирует изменения и запустит приложение.

Настройки профиля сохраняются сразу, отдельной кнопки «Сохранить» нет. Дальше можно добавить другие профили и переключаться между ними в боковом меню. Если нужно изменить имя, иконку или закрепить профиль наверху списка — нажмите на профиль правой кнопкой мыши в боковом меню.

## Возможности

### Профили

Несколько независимых пар «источник → назначение», у каждой свои настройки: запускаемый файл, режим зеркала, уведомления. Переключение — в боковом меню, у профиля своё имя и иконка.

Имя профиля по умолчанию складывается из названия папки и имени запускаемого файла, но его можно задать вручную. Иконка подхватывается из `.exe` автоматически — её тоже можно сменить.

### Копирование с проверкой

Файлы сравниваются по размеру, времени изменения и содержимому. Повторные копирования почти мгновенные: неизменённые файлы не перечитываются. Если что-то отличается, вы увидите это до начала копирования — сколько файлов добавится, изменится и удалится.

Копирование можно запускать сколько угодно раз: программа переносит только то, что действительно изменилось. В шапке профиля показывается текущая версия файлов в папке назначения.

### Резервные копии (версии)

Каждое копирование с изменениями создаёт снимок состояния папки назначения. Кнопка «Резервные копии» показывает список версий: любую можно восстановить. Перед восстановлением автоматически создаётся точка возврата — если результат не устроит, можно откатиться к тому, что было.

### Откат при отмене

Если прервать копирование или восстановление (кнопка «Отмена» или крестик), программа вернёт папку назначения к состоянию «до начала». Незаконченных «полукопий» не остаётся.

### Режим зеркала

В этом режиме из папки назначения удаляется всё, чего нет в источнике: файлы и папки. Всё удалённое сохраняется в резервную копию. Если удалить предстоит больше половины файлов, программа покажет диалог с числами — сколько файлов исчезнет из скольких — и попросит подтвердить.

### Автопроверка при запуске

Для профилей с включённой опцией копирование выполняется в фоне сразу при старте приложения. Окно при этом остаётся отзывчивым, а в статусной строке видно, что происходит.

Если профиль был восстановлен из резервной копии, автопроверка для него при старте пропускается — чтобы только что восстановленные файлы не перезаписались свежими из источника. Ручное копирование работает всегда. Это поведение можно изменить в «Настройки → Общие».

### Уведомления об изменениях

Программа периодически проверяет папки-источники и сообщает, если появились новые или изменённые файлы. Уведомления приходят, даже когда главное окно свёрнуто в системный трей.

Проверка читает только метаданные файлов — размер и время изменения, содержимое не читается, поэтому опрос идёт быстро и не нагружает диск. Интервал задаётся в «Настройки → Уведомления»: от 1 до 60 минут, по умолчанию 5. Там же настраивается, через сколько секунд уведомление скрывается само (по умолчанию — только по клику) и объединять ли сообщения нескольких профилей в одно.

Чтобы получать уведомления по конкретному профилю, включите в нём одну из галок: «Уведомлять об изменениях файлов этого источника» или «Уведомлять о сообщении из !CCRun/message.txt». В новых профилях обе выключены.

### Сообщения от автора источника

Если автор папки-источника хочет что-то передать получателю, он может положить текст в файл `!CCRun/message.txt` внутри источника — при следующей проверке получатель увидит это сообщение в уведомлении. Кнопка «Создать message.txt» в профиле создаёт такой файл с шаблоном-инструкцией. Строки, начинающиеся с `#`, считаются комментариями и получателю не показываются.

В папку назначения этот файл не копируется.

### Гибкая политика хранения бэкапов

Можно ограничить число хранимых версий (по умолчанию — последние 10) и/или удалять версии старше заданного числа дней. Обе опции — на вкладке «Настройки → Бэкапы»; удаление по возрасту по умолчанию выключено.

### Тема, трей, автозапуск

Тёмная, светлая или системная тема (по умолчанию — как в Windows). Сворачивание в системный трей. Запуск при старте Windows и запуск свёрнутым — в «Настройки → Общие».

В меню значка в трее два пункта: «Показать» — вернуть окно, и «Выход» — закрыть программу полностью.

### Длинные пути

Поддерживаются пути длиннее 260 символов — например, внутри `node_modules` или глубоко вложенных папок сборки. Учтите: стандартный диалог выбора папки в Windows не умеет открывать такие пути — это ограничение самой системы, а не программы. Скопировать и запустить из уже настроенного профиля можно без проблем.

## Где хранятся данные

Всё — в папке «Документы» пользователя:

```text
%USERPROFILE%\Documents\CheckCopyRun\
```

| Путь | Что там |
|---|---|
| `settings.dat` | Настройки приложения и список профилей. Файл зашифрован — читать его вручную бесполезно. |
| `log\app.log` | Лог работы приложения (с ротацией). |
| `icons\` | PNG-иконки, извлечённые из `.exe` профилей. |
| `monitor\` | Снимки источников для уведомлений. Служебные данные, трогать не нужно. |

Кроме того, в папке назначения каждого профиля создаётся служебная папка `!CCRun\`. Туда программа складывает резервные копии и служебные файлы. Управлять ими вручную не нужно — всё делается через интерфейс: список версий, восстановление, удаление.

Резервные копии относятся к конкретной папке назначения, поэтому при переносе профиля на другой компьютер их нужно переносить вместе с папкой назначения — иначе список версий для нового пути будет пустым.

Удаление `settings.dat` сбрасывает программу к состоянию «первый запуск»: пропадут профили и настройки. Резервные копии в папках назначения при этом останутся на месте.

## Устранение неполадок

- **«Файл приложения не найден» после копирования.** Проверьте, что «Запускаемое приложение» в профиле указывает на файл внутри папки-источника (относительный путь), и что копирование завершилось без ошибок.
- **Не приходят уведомления.** Проверьте «Настройки → Уведомления → Включить уведомления». Затем в самом профиле — галки «Уведомлять об изменениях файлов этого источника» и «Уведомлять о сообщении из !CCRun/message.txt». По умолчанию в новых профилях они выключены.
- **Скопировалось «всё заново», хотя ничего не менял.** Проверьте, включён ли «Настройки → Общие → Использовать кэш хэшей при сравнении файлов». Если он включён, а копирование всё равно долгое, возможно, изменилось время модификации файлов — так бывает после распаковки из архива.
- **«Папка назначения не существует» при восстановлении.** Проверьте, что папку не переименовали и не удалили: резервные копии привязаны к её пути.
- **Уведомление не закрывается само.** По умолчанию автоскрытие выключено, и уведомление висит до клика. Настройте в «Настройки → Уведомления → Скрывать через N сек.».
- **Не открывается файл из уведомления.** Программа пробует ассоциацию Windows, затем Блокнот, затем Проводник. Если ничего не сработало, покажется диалог с путём к файлу — его можно скопировать.
- **Windows предупреждает при запуске.** SmartScreen показывает предупреждение для программ без цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
