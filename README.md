# CheckCopyRun

Утилита для Windows: проверка, копирование и запуск приложений из папки-источника
в папку назначения по профилям.

## Что делает

- Хранит набор **профилей** (источник → назначение + путь к `.exe`).
- Сравнивает содержимое источника и назначения, показывает расхождения.
- Копирует в назначение с версионированием (CAS: блобы + состояния),
  поддерживает зеркальный режим и резервные версии для откатa.
- Запускает приложение из папки назначения после копирования.
- Умеет проверять профили при старте, работать в трее и в автозапуске.

## Стек

Python 3.12, CustomTkinter, Pillow, pystray, pywin32. Сборка — Nuitka.

## Запуск

```bat
uv run main.py
```

## Сборка

```bat
uv run build.py
```

Результат — `CCRun.exe` (имя задаётся в `build.py`). Иконка — `assets/icon.ico`.

## Где лежат данные

Всё хранится в `Documents\CheckCopyRun\`:

| Путь | Назначение |
|---|---|
| `settings.dat` | настройки приложения (DPAPI) |
| `profiles.json` | профили |
| `icons/` | пользовательские иконки профилей |
| `log/app.log` | лог с ротацией |

В папке назначения создаётся служебный каталог `!CCRun/`:

| Путь | Назначение |
|---|---|
| `blobs/` | содержимое файлов по SHA-256 |
| `states/` | снимки состояний (версии, точки возврата) |
| `hashes.json` | кэш хэшей источник↔назначение |
| `current.json` | указатель на текущую версию |

## Структура проекта

```
main.py          точка входа
config/          константы приложения
core/            модели, пути, длинные пути, настройки, I/O
services/        бизнес-логика (cas, copy, restore, system, common)
ui/              CustomTkinter: окна, вкладки, компоненты, диалоги
utils/           логирование
tools/           вспомогательные утилиты разработчика
tests/           pytest
```

Правило слоёв: `services/` не импортирует `ui/`, `tkinter` и `customtkinter`.
